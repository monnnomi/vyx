# VYX на Zomro

Переезд разрешён владельцем 14 ноября 2026 года после блокировки Vercel по лимиту трафика. Переносится только VYX; ORBITA не изменяется. Проверяйте актуальный DNS и состояние служб перед следующим выпуском.

## Размещение

- Домен: `https://joinvyx.com`, админка `/admin`; X callback сохраняется: `/api/auth/callback/x`.
- VPS Zomro: `188.137.245.224`, Ubuntu 24.04, Node 24, nginx, systemd.
- API слушает только `127.0.0.1:4173`; снаружи доступен через nginx и HTTPS.
- Код: `/opt/vyx/releases/<release>`, текущий выпуск — `/opt/vyx/current`.
- База: прежний независимый Neon PostgreSQL. Данные и подтверждённые VP не переносились в новую пустую базу и не пересчитывались.
- Секреты: `/etc/vyx/vyx.env`, root, режим `0600`. Не выводите содержимое в чат, журналы или Git.
- Новые вложения: `/var/lib/vyx/media`, пользователь `vyx`; каталог за пределами `public/`. Сохраняются авторизация, права аудитории, ограничения и диапазоны видео.
- Старый проект Vercel и Blob сохраняются для восстановления файлов. Сброс лимитов/покупка тарифа не разрешены автоматически.

## Публикация

Из существующего checkout, после необходимых тестов и отправки исходников в GitHub:

```sh
./deploy/zomro/deploy.sh
```

Нужен существующий SSH-доступ к `vyx-zomro`; локальный конфиг по умолчанию `.data/zomro/ssh_config` игнорируется Git. Можно указать другой через `VYX_SSH_CONFIG`. Скрипт собирает публичные ресурсы, отправляет только код и ресурсы (без env, Git, тестовых данных), устанавливает производственные зависимости, переключает выпуск и проверяет `/healthz`. При неудаче возвращает предыдущий выпуск. Изменения systemd/nginx применяются отдельно после проверки конфигурации. Git push сам по себе больше не обновляет живой сайт.

Проверка: `systemctl status vyx`, `curl -fsS http://127.0.0.1:4173/healthz`, `nginx -t`. Журналы приложения: `journalctl -u vyx`. В nginx используется формат без query string, чтобы не записывать OAuth-коды. Не включайте логирование тел/заголовков авторизации.

## Фоновые задачи и данные

- `vyx-news.timer`: каждые 15 минут UTC; сначала проверка заданий, затем новости, с прежними отдельными лимитами $1/сутки. Не увеличивать лимиты и не сбрасывать расход для QA.
- `vyx-farm.timer`: каждые 4 часа UTC. Используются прежние блокировки и идемпотентные начисления.
- `vyx-backup.timer`: ежедневно в 02:30 UTC, семь последних завершённых копий базы и приватных медиа в `/var/backups/vyx`. Каталог `0700`, файлы `0600`. Первичная копия перед переездом — `/root/vyx-backups/pre-zomro.dump`.
- Копии на этом же VPS защищают от ошибочных изменений, но не от потери самого сервера. Отдельный внешний бэкап пока не подключён.
- GA4 и Яндекс Метрика используют прежние счётчики. Vercel Analytics выключена для Node-размещения: её endpoint привязан к Vercel.

## Проверка переноса и известные ограничения

Общие тесты окончательного выпуска: 286 passed, 0 failed. Приватное файловое хранилище проверено изолированно: сборка частей, типы, точные диапазоны и запрет обхода путей. Перед переключением проверены живые API на VPS: корень 200, комнаты 200, админский API без сессии 401. Резервный дамп PostgreSQL 18 прочитан через `pg_restore --list`; ежедневный бэкап выполнен успешно.

На момент подготовки Vercel блокирует скачивание прежних 36 вложений (121409275 байт): HTTP 403 `Your store is blocked`, включая запросы с действующим ключом. Манифест сохранён в игнорируемой `.data/zomro/media-manifest-response.json`; скрипт импорта `.data/zomro/import-media.mjs` переносит и проверяет размеры/хеши после разрешённого восстановления доступа. Исходное хранилище не удалять. До импорта прежние вложения недоступны; новые загрузки обслуживает VPS.

`X_NEWS_BEARER_TOKEN` отсутствует в локальных исходниках и на VPS. В Vercel он сохранён как Secret: интерфейс прямо сообщает, что сохранённое значение нельзя прочитать. Ранее разрешённый резервный `X_BEARER_TOKEN` ORBITA тоже Secret. Сборщик новостей ожидает исходный ключ владельца; повторная диспетчеризация без ключа заблокирована. Проверки заданий работают независимо. Не подменять ключ OAuth-токеном пользователя и не расширять права X.

## Подтверждённый результат переключения

Реестр .com подтвердил делегирование четырём NS Zomro. На новом DNS сохранены прежние пять MX, SPF TXT и три CAA; root и www направлены на VPS. Выпущен сертификат Let’s Encrypt для обоих адресов до 12 февраля 2027 года, включено автоматическое продление. HTTP переводится на HTTPS, www — на основной домен. В firewall разрешены веб-порты 80/443, прежние ограничения остальных портов сохранены. Прямой внешний HTTPS-запрос вернул 200; state API подтвердил `authReady` и `mediaReady`.

Все три таймера VPS включены. Старый production Vercel дополнительно поставлен на обратимую Pause Project: интерфейс показывает Resume Project. Настройки, интеграции и данные Vercel сохранены. Не возобновлять старую публикацию или её расписание одновременно с VPS.

Перед финальным выпуском в Chrome подтверждена существующая сессия владельца и доступ к сохранённой ленте. Новые входы X сохраняют прежний callback; авторизация для QA не расширялась. Дамп перед переездом также скопирован на Mac в игнорируемую `.data/zomro/pre-zomro.dump` с правами 0600. После будущего импорта старых файлов установить владельца каталога медиа `vyx:vyx`.
